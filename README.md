# 🛣️ PK ADM - نظام تتبع النقاط الكيلومترية وإدارة مسارات الطريق السيار
**Système de suivi des Points Kilométriques (PK) et gestion des itinéraires autoroutiers (A3 / A7)**

تطبيق ويب خرائطي تفاعلي مصمم لتحديد النقاط الكيلومترية والمترية (`PK+M`) بدقة على شبكة الطرق السيارة، وتوجيه بلاغات المساعدة الميدانية، وحساب وتدقيق الكيلومترات المقطوعة لدوريات السلامة.

## ✨ المميزات الرئيسية | Fonctionnalités principales

### 1. للمستعملين والسائقين (واجهة الهاتف المبسطة - Mobile SOS)
* **تحديد الموقع الدقيق (GPS):** حساب النقطة الكيلومترية والمترية الفورية (مثل `PK 209+103`) وتحديد المحور والاتجاه (`CA` / `AC`).
* **الحماية من البلاغات العبثية (Smart Geofencing):** لا تظهر أزرار طلب المساعدة (`SMS` / `WhatsApp`) إلا بعد التحقق التلقائي من:
  1. توقف المركبة الفعلي (السرعة أقل من 5 كم/س).
  2. التواجد داخل نطاق الطريق السيار أو بدالاته.
  3. جودة إشارة الأقمار الصناعية (`GPS Accuracy`).
* **التوجيه الجغرافي التلقائي (Geographic Routing):** توجيه رسالة الاستغاثة تلقائياً إلى رقم هاتف مركز المراقبة المسؤول عن المقطع الكيلومتري.
* **العمل بدون إنترنت (Offline Mode):** دعم العمل في المناطق ضعيفة التغطية عبر `Service Worker` وإرسال الإحداثيات عبر الرسائل القصيرة (`SMS`).

### 2. للإدارة والمراقبة (واجهة الحاسوب - Admin & Audit)
* **إدارة المحاور والبدالات (`Échangeurs` & `Pénétrantes`):** عرض المسارات المزدوجة المتوازية ووصلات البدالات بترقيم كيلومتري مستقل.
* **إضافة المنشآت وباحات الاستراحة:** تثبيت مواقع الباحات والمحطات مع شعاراتها (`Logos`) وخطوط ربط متجاوبة مع مستوى التكبير (`Zoom`).
* **تدقيق ملفات الإكسل (`Excel / CSV Audit`):** استيراد جداول حركات مركبات الدورية (`M1` - `M6`)، ورسم مساراتها ونقاط نصف الدورة (`1/2 Tour`) على الخريطة، ومقارنة المسافة الفعلية (`Parcouru Réel`) بالمسافة النظرية (`Parcouru Théorique`).
* **تعديل المسارات بالماوس:** إمكانية سحب وتعديل إحداثيات الطريق مباشرة على الخريطة وتصديرها.
* **حماية لوحة الإدارة:** تأمين قائمة الأدوات بكلمة مرور (`Password Protection`) لمنع التعديل غير المصرح به.
* **دعم ثنائي اللغة:** تبديل فوري للواجهة بين **العربية (`RTL`)** و **الفرنسية (`LTR`)**.

## 📂 هيكل ملفات المشروع | Structure du projet

* `index.html` : الواجهة الرئيسية المتجاوبة (للحاسوب والهاتف).
* `style.css` : ملف التنسيق وتصميم الأشرطة والبطاقات ووضع الهاتف.
* `script.js` : المنطق البرمجي، حسابات `Turf.js`، قراءة الإكسل، والتوجيه الجغرافي.
* `routes.js` : قاعدة بيانات إحداثيات المحاور، البدالات، وباحات الاستراحة الدائمة.
* `sw.js` : ملف `Service Worker` لتشغيل التطبيق بدون اتصال بالإنترنت.
* `image/` : مجلد يحتوي على شعارات باحات الاستراحة ومحطات الوقود.

## 🛠️ التقنيات المستخدمة | Technologies utilisées
* **HTML5 / CSS3 / Vanilla JavaScript**
* **Leaflet.js** (عرض الخرائط التفاعلية)
* **Turf.js** (التحليل الهندسي والمكاني وحساب المسافات بدقة المتر)
* **Leaflet-Geoman** (تعديل المسارات هندسياً على الخريطة)
* **SheetJS (XLSX)** (استيراد وتدقيق وتصدير ملفات الإكسل)
